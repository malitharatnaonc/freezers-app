# Freezers

This repository contains two implementations:

- `freezers_app/`: the original Streamlit app
- `freezers_desktop/`: the React + Electron desktop prototype with a boxes.bio-style layout

## React desktop prototype

The new desktop app runs from a local snapshot JSON file and is intended as the path away from the Streamlit UI.

```bash
cd /Users/ratnawm/projects/freezers/freezers_desktop
npm install
npm run dev
```
