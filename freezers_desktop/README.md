# Freezers Desktop

React + Electron desktop shell for the freezer inventory app.

## Install

```bash
cd /Users/ratnawm/projects/freezers/freezers_desktop
npm install
```

## Run

```bash
npm run dev
```

The app opens as a desktop window. It loads and saves a local `freezers.snapshot.json` file by default in the Electron user-data folder, and supports opening/saving alternate snapshot files.
